## 环境配置
python 3.10.22
torch 2.7.0
cuda 12.8

## 使用说明
运行 camera_predict.py，将脸放入绿色框内，点击按钮或者空格即可识别你是否带眼镜。

## 开发说明
除camera_predict.py 外，其他皆为古法手搓编程。

## 感悟
我已经红温，一开始做人脸表情识别，训练好模型后测试准确度只有百分之七十，后来才知道是人脸噪声大，resnet在此泛化能力弱，无法精确识别，遂放弃。结果一不小心把写的resnet模型全删了，只得从头手写。后来改做asl美国手语的手势识别，结果下载的数据是绿幕背景，导致模型只学到了绿色背景，并且过拟合严重，完全不能用。后来又找了一个用游戏截图做的不同背景的手势数据集训练了两个小时，结果因为游戏光线与现实不符，准确率低的惊人。最后才做这个眼镜识别。
